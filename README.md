# Архив красивых визуализаций

Галерея графиков, сетей и карт с локальными превью, описаниями данных и ссылками на оригинальные работы.

В коллекции 47 опубликованных графиков, 57 опубликованных карт, 55 локальных демо графиков и 20 демо карт. Есть блоки «Одни данные, три графика» на данных NASA GISTEMP и «Одни данные, три карты» на данных переписи населения США.

## Запуск

Скачайте репозиторий и откройте index.html в браузере. Моушен-версия находится в папке «Моушен-версия». В шапке каждой версии есть ссылка для перехода в другую.

Превью и локальные демонстрации работают без интернета. Для просмотра оригиналов нужен доступ к сайтам авторов.

## Источники

При подборе графиков сначала рассматривается [Apache ECharts](https://echarts.apache.org/examples/en/index.html#chart-type-line). Дополнительные примеры взяты из [Observable Gallery](https://observablehq.github.io/notebook-kit/gallery), [D3 notebooks](https://observablehq.com/@d3), научных публикаций и авторских проектов. Визуальные референсы моушен-версии включают [MotionSites](https://motionsites.ai/).

Авторы, данные, оригиналы и источники превью указаны в карточках. При использовании сторонних работ действуют условия их авторов.
